SC Launcher · 비방장 인게임 기능 수정 (2026-10-07)
빌드: nonhost-control-fix-20261007
실행 파일: 이 폴더의 SC-Launcher.exe
대상: StarCraft 1.23.10.13515 x64

방장이 아닌 게임에서 선택 정보와 컴퓨터 목록까지 숨겨지던 공통 게임 진행
판정을 수정했습니다. 본인 유닛 제어와 본인 → 컴퓨터 동맹은 방장 여부와
관계없이 사용합니다. 로비 슬롯 변경은 방장일 때만 사용할 수 있습니다.

적용
1. 새 모듈을 적용할 때 스타와 기존 런처를 완전히 종료합니다.
2. 이 폴더의 SC-Launcher.exe를 실행하고 스타에 연결합니다.
3. 다른 사람이 만든 방에 들어가 본인 유닛을 선택합니다.
4. 선택 정보가 표시되는지 확인한 뒤 백틱(`)으로 같은 종류 전체를 제어합니다.
   우클릭, 정지, 공격, 라바·일반 생산 건물 생산과 랠리를 확인합니다.
5. 컴퓨터가 있으면 동맹창에서 컴퓨터 체크 → 확인 후 관계 유지도 확인합니다.
6. 스타와 런처를 종료하지 않고 다음 판에 들어가 같은 기능을 확인합니다.
   각 게임에서 본인 유닛을 새로 선택하고 백틱을 새로 누릅니다.

동맹은 내 플레이어 → 해당 컴퓨터의 관계만 변경합니다.
컴퓨터 체크는 즉시 변경을 요청하며 확인 버튼 출력에도 반영합니다.
취소/Esc는 이미 보낸 변경을 되돌리지 않습니다. 맵 트리거가 동맹을 다시
바꾸는 경우 오래된 관계를 강제로 반복 전송하지 않습니다.

직전 재연결 수정본은 사용자가 두 판 연속 정상 작동을 확인했습니다.
이번 비방장 수정본의 실게임 검증은 아직 남아 있습니다.
이번 작업은 자체 검사·컴파일·배포 파일 생성만 수행했습니다.
설치 게임 파일을 수정하거나 게임을 실행·조작하지 않았습니다.
검사 결과는 TEST-REPORT.md와 verification 폴더를 참고하세요.
