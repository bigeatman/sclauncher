SC Launcher · 미니맵 공격 위치 지정 시 전체 제어 수정 (2026-10-09)
빌드: minimap-command-fix-20261009
실행 파일: 이 폴더의 SC-Launcher.exe
대상: StarCraft 1.23.10.13515 x64

백틱 전체 제어 후 공격 위치를 미니맵에서 클릭할 때,
미니맵 콜백이 실제로 만든 명령을 나머지 같은 종류의 본인 유닛에도 전달합니다.
좌표와 목표, 예약 여부는 게임이 만든 명령 그대로 사용합니다.
공격 명령 없이 카메라만 옮기는 클릭은 전체 명령으로 만들지 않습니다.
실게임 확인은 아직 남아 있습니다.

적용과 확인
1. 새 모듈 적용을 위해 스타와 기존 런처를 완전히 종료합니다.
2. 이 폴더의 SC-Launcher.exe를 실행하고 스타에 연결합니다.
3. 같은 종류의 본인 유닛을 여러 마리 준비합니다.
4. 한 마리 선택 → 백틱으로 전체 제어를 켭니다.
5. 공격 버튼(A)을 누른 뒤 미니맵의 목적지를 클릭합니다.
6. 직접 지형 클릭, 미니맵 우클릭과 Shift 예약도 확인합니다.
7. 공격 모드 없이 미니맵을 클릭하면 카메라만 움직이는지 확인합니다.
8. 다음 판에서는 본인 유닛을 새로 선택하고 백틱을 새로 누릅니다.

생산 건물 랠리, 라바·러커 변태, 이동·정지·공격 처리는 유지합니다.
자원·인구수·업그레이드·생산 가능 여부는 게임의 기존 규칙을 따릅니다.
본인 유닛 제어와 본인 → 컴퓨터 동맹은 방장 여부와 관계없이 사용합니다.
로비 슬롯 변경은 방장일 때만 사용할 수 있습니다.
동맹은 내 플레이어 → 해당 컴퓨터의 관계만 변경합니다.
컴퓨터 체크는 즉시 변경을 요청하며 확인 버튼 출력에도 반영합니다.
취소/Esc는 이미 보낸 변경을 되돌리지 않습니다. 맵 트리거가 관계를 다시
바꾼 경우 오래된 관계를 강제로 반복 전송하지 않습니다.

이번 작업은 소스 수정·자체 검사·컴파일·배포 파일 생성만 수행했습니다.
설치 게임 파일을 수정하거나 게임을 실행·조작하지 않았습니다.
