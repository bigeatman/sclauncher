SC Launcher · 히드라 전체 제어 후 러커 변태 수정 (2026-10-09)
빌드: hydralisk-lurker-fix-20261009
실행 파일: 이 폴더의 SC-Launcher.exe
대상: StarCraft 1.23.10.13515 x64

백틱으로 히드라 전체 제어를 켠 뒤 러커 변태를 누르면,
원래 선택한 히드라를 제외한 나머지 본인 히드라에도 명령을 전달합니다.
먼저 변태한 히드라가 러커 알로 바뀌어도 나머지 전달을 이어갑니다.
실게임 확인은 아직 남아 있습니다.

적용과 확인
1. 새 모듈 적용을 위해 스타와 기존 런처를 완전히 종료합니다.
2. 이 폴더의 SC-Launcher.exe를 실행하고 스타에 연결합니다.
3. 히드라 여러 마리와 러커 업그레이드, 충분한 자원·인구수 여유를 준비합니다.
4. 히드라 한 마리를 선택하고 백틱(`)을 눌러 전체 수를 확인합니다.
5. 러커 변태 버튼을 한 번 눌러 나머지 히드라도 변태하는지 확인합니다.
6. 생산 단축키와 히드라 여러 마리를 직접 선택한 경우도 확인합니다.
7. 다음 판에서는 본인 유닛을 새로 선택하고 백틱을 새로 누릅니다.

자원·인구수·업그레이드·변태 가능 여부는 게임의 기존 규칙을 따릅니다.
라바 생산, 건물 생산·랠리, 이동·정지·공격 처리도 유지합니다.
본인 유닛 제어와 본인 → 컴퓨터 동맹은 방장 여부와 관계없이 사용합니다.
로비 슬롯 변경은 방장일 때만 사용할 수 있습니다.
동맹은 내 플레이어 → 해당 컴퓨터의 관계만 변경합니다.
컴퓨터 체크는 즉시 변경을 요청하며 확인 버튼 출력에도 반영합니다.
취소/Esc는 이미 보낸 변경을 되돌리지 않습니다. 맵 트리거가 관계를 다시
바꾼 경우 오래된 관계를 강제로 반복 전송하지 않습니다.

설치 게임 파일을 수정하거나 게임을 실행·조작하지 않았습니다.
