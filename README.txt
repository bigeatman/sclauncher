SC Launcher · 건물 전체 제어 생산 버튼 수정 (2026-10-07)
빌드: building-production-click-fix-20261007
실행 파일: 이 폴더의 SC-Launcher.exe
대상: StarCraft 1.23.10.13515 x64

백틱으로 같은 종류 건물 전체 제어를 켠 뒤 생산 버튼을 누를 때,
원래 선택한 건물의 생산 명령을 관찰해 나머지 건물에도 하나씩 전달하도록
누락된 버튼 활성화 경로를 연결했습니다. 실게임 확인은 아직 남아 있습니다.

적용
1. 새 모듈 적용 시 스타와 기존 런처를 완전히 종료합니다.
2. 이 폴더의 SC-Launcher.exe를 실행하고 스타에 연결합니다.
3. 같은 종류의 완성된 생산 건물을 여러 개 준비합니다.
4. 한 건물을 선택하고 백틱(`)을 눌러 전체 건물 수를 확인합니다.
5. 자원과 인구수 여유가 있는 상태에서 생산 버튼을 한 번 누릅니다.
   각 건물의 생산 대기열이 한 칸씩 늘어나는지 확인합니다.
   커맨드 센터의 SCV, 배럭 생산, 연속 클릭, 단축키부터 확인하면 됩니다.
6. 랠리와 라바 생산도 확인합니다. 생산 제한은 게임의 기존 규칙을 따릅니다.
7. 다음 판에서는 본인 유닛을 새로 선택하고 백틱을 새로 누릅니다.

본인 유닛 제어와 본인 → 컴퓨터 동맹은 방장 여부와 관계없이 사용합니다.
로비 슬롯 변경은 방장일 때만 사용할 수 있습니다.
동맹은 내 플레이어 → 해당 컴퓨터의 관계만 변경합니다.
컴퓨터 체크는 즉시 변경을 요청하며 확인 버튼 출력에도 반영합니다.
취소/Esc는 이미 보낸 변경을 되돌리지 않습니다. 맵 트리거가 관계를 다시
바꾼 경우 오래된 관계를 강제로 반복 전송하지 않습니다.

이번 작업은 자체 검사·컴파일·배포 파일 생성만 수행했습니다.
설치 게임 파일을 수정하거나 게임을 실행·조작하지 않았습니다.
검사 결과와 버튼 관찰 진단은 TEST-REPORT.md를 참고하세요.
